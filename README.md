# Utopia dinner menu

A mobile-first restaurant QR menu prototype built with React, Vite, Tailwind CSS, and HeroUI OSS.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

## Deploy on Vercel

Import this GitHub repository into Vercel. It will detect Vite automatically; use `npm run build` as the build command and `dist` as the output directory.

## Content note

The menu items are clearly labelled demonstration content used to make the prototype interactive. Replace them with restaurant-approved menu, dietary, allergy, offer, pairing, image, and availability data before publication.
